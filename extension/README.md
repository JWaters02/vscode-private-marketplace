# VS Code Private Marketplace (Extension)

## Changelog

### 1.0.0

**New Features & Changes**
- Add `Approved Extensions` tree view to fetch, download & install extensions
- Add `Updated Extensions` tree view to view, download & install extensions that have updates pending
- Add the ability to download & install `zowe.config.json` and `zowe.schema.json` files if they have pending updates
- Prevent the user from installing or updating unapproved extensions from the public marketplace
